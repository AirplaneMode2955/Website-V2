# Lessons

- Site traffic is low: design social/competitive features so they work with one player a day (use Jett as the always-present opponent), never ones that need a crowd.
- Humor for the site should be sharp self-roast with a twist, not mild stat jokes; a live resetting "seconds since Jett last…" timer landed best.
- For animated figures, confirm the camera angle before changing motion; "backwards" here meant the swing should read as a right-hander filmed from the target (back to viewer's left, finish to the right, wrapped over the head).

# Jett Iverson — Personal Website (V2)

Personal portfolio and professional site for Jett Iverson — marketer, husband, and AI
strategist based in Utah. Live at [jettiverson.com](https://jettiverson.com).

## Stack

- **Next.js 15** (App Router) + **React 19**
- **TypeScript**
- **Tailwind CSS 3**
- **Framer Motion** for animation (respects `prefers-reduced-motion`)
- **next/font** — Newsreader (headline) & Manrope (body); Material Symbols via Google Fonts
- Analytics: Vercel Analytics + GA4 (`@next/third-parties`)
- Tests: **Vitest**
- Hosted on **Vercel**

## Routes

| Route | Notes |
|---|---|
| `/` | Hero, about teaser, background, featured projects, case-study numbers, content, photo bank, contact CTA |
| `/about` | Full story + timeline |
| `/resume` | Web resume (PDF generated by `npm run resume:pdf`) |
| `/projects` | Project index |
| `/content` | Articles — on-site (`/content/[slug]`) and off-site links; data in `src/lib/articles.ts` |
| `/case-studies` | Results overview + `/case-studies/[slug]`; data in `src/lib/caseStudies.ts` |
| `/contact` | Contact links |
| `/play` | The Arcade — hosted games under `public/arcade/<slug>/` wrapped by `/play/[slug]`; data in `src/lib/arcadeGames.ts` |
| `/play/gut-check` | Daily marketing-judgment game; logic + tests in `src/lib/gutCheck/` |

SEO surfaces are generated at build time: `src/app/sitemap.ts`, `src/app/robots.ts`,
`src/app/manifest.ts`, plus `Person` JSON-LD in `src/app/layout.tsx`.

## Develop

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm run start      # serve the production build
npm run lint
npm test           # vitest run
npm run resume:pdf # regenerate public/resume.pdf
```

## Images

Photos live in `public/`. Source files are pre-compressed (resized to ~2000px on the
long edge, mozjpeg q80) before commit — the raw originals are kept locally in
`image-originals/` (git-ignored), not deployed. Re-run the compression pass if you drop
new large photos in `public/`.
